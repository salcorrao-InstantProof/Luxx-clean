# LUXX Integrated Hosted v1.3 — Acceptance Contract

## A. Code release gate — must pass before packaging
1. 30/30 domain/integrity tests.
2. 21/21 server/API functions.
3. 41/41 failure/security tests.
4. Browser UI: 22 workflow groups, 48/48 handlers, zero page/console errors.
5. Real the full source duration master: immutable hash, rendered 5:00 main cut, three rendered teasers, HLS previews, second-generation video edit, restart persistence.
6. Photo: immutable master, AUTO BEST derivative, edit-an-edit derivative, restart persistence.
7. JSON/CSV export and JSON import.
8. Brand-shoot draft/approval.
9. Historical-video review/prospective update.
10. Build/static/syntax/LUXX-only checks.

## B. Production Netlify + iPhone gate — run immediately after first deploy
1. Open the one HTTPS LUXX URL in iPhone Safari.
2. Log in with the private LUXX passcode.
3. Upload one real photo; confirm it appears in LIBRARY.
4. Close Safari completely; reopen the same URL; confirm the photo remains.
5. Use EDIT → AUTO BEST; confirm derivative appears and original still opens unchanged.
6. Upload the real the full source duration video; confirm the original is fully saved before processing begins.
7. Close Safari while/after processing; reopen; confirm asset/job remains.
8. Confirm rendered MAIN-CUT and teaser variants are present and playable.
9. Use video EDIT on the MAIN-CUT; confirm a new derivative is created without replacing the master or MAIN-CUT.
10. Record the video as historical on one applicable platform; run REVIEW EXISTING; confirm history is preserved and any update is prospective.
11. Capture and lock baseline.
12. Verify one real tracking route.
13. Confirm TODAY remains HOLD until baseline + authorization + availability + eligibility + tracking + variant completeness are satisfied.
14. Prepare a prescription, CHANGE it, DECLINE it, create another, APPROVE it and MARK POSTED with a real execution reference.
15. Enter a measurement, then add a correction without rewriting the first record.
16. Add a revenue event and custom order.
17. Export JSON and CSV; confirm files download.
18. Create a brand-shoot draft; creator approves it.
19. Redeploy the same code package or a harmless code-only update.
20. Reopen LUXX and confirm state, photo master, photo derivative, video master, video derivatives, historical record, prescription/action, results and revenue still exist.

The release is called **live/device certified** only after Section B passes on the actual production site and physical iPhone.
