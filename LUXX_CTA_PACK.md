# LUXX — CTA pack, 28 days

Built from four submissions. Structure from the frame+slot approach, DM framing from
the open-broadcast approach, voice kept terse enough to send one-handed.

## Two rules that make this work

**Frames, not lines.** A frame is a sentence with a swappable slot. One frame plus eight
slot-fills is eight different posts. Fixed lines run out; frames don't.

**The DM is written as an announcement, not a whisper.** It goes to 25-30 people in a
sitting. Anything implying she picked *you* falls apart the moment two fans compare
phones. "Sending this out tonight" survives that. "Just for you" does not.

**Slots are `{a / b / c}`.** Pick one. Never the same one twice running.
