LUXX v1.7.0 RC3 — ZERO-SURPRISE RELEASE
Launch date: Monday, September 7, 2026

WHAT THIS RELEASE IS

A launch-hardening patch on the existing v1.7.0 application. The architecture is
unchanged: primary navigation is still TODAY / LIBRARY / RESULTS, there is no
fourth tab, and no new engine or product was added.

WHAT CHANGED

- Cam availability is configured, never hard-coded. The RC1 evening block and its
  fixed cam days are gone. Saturday and Sunday cam is impossible everywhere.
- Week-1 PPV monetization targets OnlyFans PAID. OnlyFans Free stays nurture and
  conversion.
- A Pornhub teaser job accepts only a real teaser or trailer derivative. If none
  exists, TODAY shows HOLD / FIX LIBRARY instead of quietly using a full scene.
- PPV evidence is attached to the pre-purchase treatment everywhere it is written:
  the job card, READY TO APPROVE, the frozen prescription, RESULTS and receipts.
- PRODUCE is off until a Library or funnel gap is documented.
- IMPORT BASELINE collects every exact platform number in one upload, for review.
- TODAY resolves days in the creator's timezone (America/Chicago), not raw UTC.
